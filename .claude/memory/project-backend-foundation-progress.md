## Architecture decisions locked in (do not re-litigate without the user)

- Onion Architecture modeled directly on `C:\Users\MBEYAZBULUT\Documents\GitHub\EnvanteriX` (Core/Domain, Core/Application, Infrastructure/Persistence, Infrastructure/Infrastructure, Presentation/WebApi), CQRS via MediatR, generic `IReadRepository<T>`/`IWriteRepository<T>`/`IUnitOfWork`, per-layer `Registration.cs` DI extension pattern.
- .NET 10, PostgreSQL via Npgsql.EntityFrameworkCore.PostgreSQL.
- Deliberate deviations from EnvanteriX (per architecture audit — see [[reference-envanterix-architecture-audit]]): mandatory global query filter (`ICompanyScoped`/`ITenantScoped` marker interfaces + reflection-based `HasQueryFilter` in `OnModelCreating`) and `SaveChangesAsync` stamping — EnvanteriX has neither; plain `User`/`Assignment` entities instead of ASP.NET Core Identity (Identity's global role model can't express one user with a different role per Company/Branch); `TransactionBehavior` + `ITransactionalRequest` marker added (EnvanteriX has zero pipeline behaviors beyond validation); `BaseException.StatusCode` + corrected exception middleware (EnvanteriX maps all domain NotFound exceptions to 500 — a bug); real xUnit test projects (EnvanteriX has none); AutoMapper's EnvanteriX wrapper (static mutable `MapperConfiguration`, rebuilt per type pair) intentionally NOT carried over — manual mapping used instead for the simple DTOs in this plan.
- MediatR license note: v13+ has a commercial license tier for larger orgs — flagged in the plan (Task 5, Step 1), not yet resolved with the user; free source-generator alternative `Mediator` (martinothamar) noted as a fallback if it becomes a blocker.
- Scope split: this plan = Foundation only (solution skeleton, Domain Identity/Tenancy entities, Persistence infra, one non-auth-gated Branch CRUD vertical slice, mobile docs seed). Auth/JWT/OTP, Tenant Onboarding, Package/Membership/Freeze, Localization, AuditLog-write-on-mutation, and all Faz 2 modules are explicitly OUT of scope — separate future plans.
